# Polices de la charte

Fichiers variables originaux téléchargés le 11 novembre 2026 depuis le dépôt officiel Google Fonts, conservés sans modification. Le nom local a été simplifié pour le chargement CSS. Les licences SIL Open Font License 1.1 complètes accompagnent chaque fichier.

| Police | Source | Licence locale |
| --- | --- | --- |
| Hepta Slab | https://github.com/google/fonts/tree/main/ofl/heptaslab | HeptaSlab-OFL.txt |
| Readex Pro | https://github.com/google/fonts/tree/main/ofl/readexpro | ReadexPro-OFL.txt |
| Martian Mono | https://github.com/google/fonts/tree/main/ofl/martianmono | MartianMono-OFL.txt |

Les fichiers sont servis depuis `/fonts/` ; aucune requête Google Fonts n’est effectuée par le navigateur. Les familles de remplacement CSS restent disponibles si un fichier ne peut pas être chargé.
